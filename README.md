## Overview

PopTracker is a cross-platform tracker for randomizer games that loads community-authored packs, tracks checked locations, and integrates with Archipelago multiworld for real-time item routing.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **PopTracker** delivers the features you need in a clean, intuitive package.

</div>

## Key Features

| Feature | Description |
|---------|-------------|
| **Pack Loader** | Load community tracker packs from a local directory or URL |
| **Map Tracking** | Interactive dungeon maps marking checked and remaining locations |
| **Archipelago Sync** | Live item-received feed from Archipelago multiworld sessions |
| **Logic Hints** | Highlights locations accessible with current item state |
